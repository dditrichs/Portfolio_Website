Microsoft 365 & Entra ID Security Lab

A hands-on walkthrough demonstrating core Microsoft 365 administration, cloud user lifecycle management, Exchange Online shared mailbox delegation, and Microsoft Entra ID Zero-Trust Security policies including Multi-Factor Authentication (MFA) and Conditional Access enforcement.

Phase 1: Environment Setup

  1. Open a Private / Incognito browser window.
  2. Go to the Microsoft 365 Business Premium product page and click Try free for 1 month.
  3. Sign-Up Flow:
    • Enter your email address to get started and select Set up account.
    • Enter organization details: Damon Ditrichs, Business Name (DDSEVER Tech Lab), size: 1 person.
    • Specify sign-in identity: Set domain name prefix to ddsever (domain: ddsever.onmicrosoft.com).
    • Set Global Admin username: admin (Full Admin ID: admin@ddsever.onmicrosoft.com).
  4. Complete verification and immediately turn off recurring billing under Billing > Your products to avoid charges.

Phase 2: User Lifecycle & Identity Management

Step 2: Onboard a New Employee (User Provisioning)
  1. Navigate to Users > Active users in the Admin Center and click Add a user.
  2. Enter user details: Jordan Miller, Username: jmiller (jmiller@ddsever.onmicrosoft.com).
  3. Set temporary password settings: Automatically generate a password and enforce Require password change upon first sign-in.
  4. Assign Microsoft 365 Business Premium license and set Department to Information Technology.

Step 3: Configure Security Groups & Role-Based Access Control (RBAC)
  1. Go to Teams & groups > Active teams & groups > Security and click Add a security group.
  2. Create group named SG-IT-Support-Tier1.
  3. Under Members, add jmiller@ddsever.onmicrosoft.com to assign group-based permissions.

Phase 4: Entra ID Security & Credential Management

Step 5: Administrative Password Reset (Entra ID)
  1. Open Microsoft Entra Admin Center (entra.microsoft.com) > Identity > Users > All users.
  2. Select Jordan Miller and click Reset password in the action toolbar to generate initial sign-in credentials.

Step 6: Account Lockout Simulation & MFA Re-Registration
  1. In Entra ID under Users > Jordan Miller > Manage > Authentication methods.
  2. Click Require re-register MFA and Revoke MFA sessions to force authentication method updates for compromised or lost devices.
Step 6: MFA Revocation & Re-Registration Click to Expand

Authentication methods blade for jmiller@ddsever.onmicrosoft.com displaying session revocation and mandatory MFA re-registration enforcement.

GitHub Note: "Resolved account access lockout ticket: executed authentication session revocation and triggered mandatory Multi-Factor Authentication (MFA) re-registration in Entra ID."
Step 7: Enforce Security Controls via Conditional Access
  1. In Entra Admin Center, navigate to Protection > Conditional Access > Policies and select New policy.
  2. Name: CA001-Enforce-MFA-All-Users. Target Scope: All Users (Excluding Global Admin admin@ddsever.onmicrosoft.com to prevent lockout). Target Apps: All Cloud Apps.
  3. Grant Controls: Require Multi-Factor Authentication.
