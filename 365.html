A hands-on walk-through of core M365 administration, user lifecycle management, Exchange Online delegation, and Entra ID Conditional Access policies.

Phase 1: Environment Setup

Step 1: Set Up Your Microsoft 365 Trial Tenant

  1. Open a Private / Incognito browser window.
  2. Go to the Microsoft 365 Business Premium product page and click Try free for 1 month.
  3. Sign-Up Flow:
    • Enter your email address to get started and select Set up account.
    • Enter your name (Damon Ditrichs), business name (DDSEVER Tech Lab or DDSEVER IT), and select company size (1 person).
    • Specify your sign-in identity: Set your domain name prefix to ddsever. Your domain will be ddsever.onmicrosoft.com.
    • Set your Global Admin username: admin (Full Admin ID: admin@ddsever.onmicrosoft.com).
    • Create a strong password and save your credentials.
  4. Complete the identity text verification and finish checking out.
  5. Turn off recurring billing immediately: Once setup finishes and you land on the confirmation page, go to Billing > Your products in the portal, select your trial, and edit recurring billing to Off so you are never charged.

Step 7: Enforce Security Controls via Conditional Access

Implements Zero-Trust security rules across tenant accounts.

  1. In the Entra Admin Center, navigate to Protection > Conditional Access > Policies.
  2. Click New policy.
  3. Set Name: CA001-Enforce-MFA-All-Users.
  4. Under Assignments:
    • Users: Select All users (Click Exclude and select your Global Admin account admin@ddsever.onmicrosoft.com to prevent administrative lockout).
    • Target resources: Select All cloud apps.
  5. Under Access controls > Grant:
    • Select Grant access, check Require multifactor authentication, and click Select.
  6. Set Enable policy to Report-only (or On) and click Create.
