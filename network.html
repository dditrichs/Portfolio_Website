Active Directory Infrastructure & Provisioning

This project demonstrates the complete deployment, configuration, and automated management of an enterprise-grade Windows Server environment using Oracle VirtualBox. Built to model core corporate infrastructure workflows under the custom domain mydomain.com, the environment encompasses Active Directory Domain Services (AD DS), Routing and Remote Access (RRAS) NAT, DHCP scope allocation, PowerShell bulk object provisioning, and client workstation domain integration.

Infrastructure Architecture & Automation Workflow

To showcase professional systems administration capabilities, the lab was engineered to handle core network services—ranging from foundational hypervisor configuration and directory promotion to automated user provisioning via PowerShell and client domain binding.

Domain Controller VM Configuration Click to Expand

Initial setup and configuration of the Windows Server 2019 Standard Evaluation domain controller VM within Oracle VirtualBox. This view outlines hardware allocations, nested virtualization parameters, and dual network adapters configured for NAT and internal network routing.

Active Directory Domain Promotion Click to Expand

Active Directory Users and Computers (ADUC) management console validating the successful promotion of the Windows Server instance to a domain controller for the custom forest root mydomain.com.

Routing, Remote Access & NAT Configuration Click to Expand

Routing and Remote Access Service (RRAS) management console configured with Network Address Translation (NAT). This setup enables domain-joined clients on the internal subnet to securely route internet traffic through the domain controller gateway.

DHCP Scope Deployment & Lease Management Click to Expand

DHCP server role deployment configured with an active IPv4 scope range (`172.16.0.0/16` with pool `172.16.0.100-200`) to automate dynamic IP address allocation for internal network clients.

PowerShell Automated Bulk User Provisioning Click to Expand

Windows PowerShell ISE executing an automated script to parse a dataset, generate secure credentials, create organizational units, and provision user accounts into the designated security group with password policies enforced.

Client Workstation Domain Integration Click to Expand

Verification of client workstation network configuration pointing to the domain controller, displaying a successful DHCP lease assignment (`172.16.0.100`) and active domain connectivity to mydomain.com.
